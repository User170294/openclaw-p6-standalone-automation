# MEMORY - Bodega Simtexx

## Decisiones vigentes
- Proyecto orientado a cuadratura de insumos + trazabilidad entrada/salida.
- Se prioriza un enfoque simple, auditable y escalable.

## Pendientes clave
- Confirmar número de bodegas involucradas.
- Definir sistema origen de datos (ERP, Excel, ambos).
- Establecer periodicidad de cuadratura por bodega.
- Definir responsables por etapa (recepción, despacho, ajuste, aprobación).

## Riesgos iniciales
- Datos incompletos o no estandarizados.
- Diferencias entre registro manual y sistema.
- Falta de disciplina operacional en cierres diarios.

## Supuestos
- Habrá al menos una bodega piloto para validación.
- Se puede iniciar con plantillas simples antes de automatizar.
