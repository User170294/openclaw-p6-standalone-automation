# Proyecto: Finanzas

## Objetivo
Construir un flujo confiable para gestionar datos financieros (Excel/PBIX y otras fuentes), estandarizarlos y automatizar informes.

## Alcance inicial (Fase 1)
1. Inventario de fuentes de datos
2. Diccionario de datos (campos, definiciones, dueños)
3. Reglas de calidad y validación
4. Diseño de modelo analítico (Power BI / capa intermedia)
5. Propuesta de automatización de actualización y reportes

## Entregables esperados
- Mapa de datos y dependencias
- Catálogo de métricas financieras
- Diseño de pipeline automatizado
- Plantilla de informe mensual automatizable
